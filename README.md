# A.K. Soft Games

The studio's site: https://kulykandrii.github.io/aksoftgames/ (GitHub Pages from `main`).

One page, `index.html`, with everything inline; `assets/` holds the game icons, short muted gameplay loops
(360 px wide, 8 s) with their posters, the favicon and the share image. When a game goes live in the App Store,
swap its "Coming soon" status for a store button like Space Adventure's.

Store buttons are App Store campaign links, so App Store Connect (App Analytics, Acquisition, Campaigns) counts the
downloads that came from the site: `https://apps.apple.com/app/apple-store/id<app id>?pt=128585058&ct=site&mt=8`
(`pt` is the studio's provider id, `ct` the source; in HTML the `&` is written `&amp;`). The same link with
`ct=youtube`, `ct=instagram` or `ct=tiktok` goes in those profiles.
